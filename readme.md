# 识玥网页剪藏（shiyue-webclip）

Obsidian 网页剪藏插件：把 **X(Twitter) 推文、微信公众号文章、小红书笔记、今日头条文章、普通网页** 一键剪藏进知识库，按规则自动分类归档、图片本地化、链接去重。界面和文档全是简体中文，专为中文内容平台设计。自研插件，不是任何国外插件的翻译版。

> 版本 1.5.1 · 作者：识玥 · 需要 Obsidian 1.4.0+

---

## ✅ 能做什么

- **一键剪藏**：复制链接 → 点左侧栏图标 → 确认入库；也可以命令面板输入链接、批量粘贴多行、或直接粘贴正文兜底
- **自动分类归档**：本地规则引擎（离线、毫秒级），按关键词命中自动放进对应文件夹、打标签；可选接 LLM 分类，接口挂了自动回退规则，不阻塞剪藏
- **图片本地化**：正文图片自动下载进附件目录，单张失败不断链（保留原图链并在笔记里告警）
- **链接去重**：同一链接再剪会问你是「重新剪一份」还是「跳过」，批量时自动跳过不弹窗
- **英文自动翻译**（可选）：启用 LLM 后，英文内容自动译成中文，中文翻译在前、英文原文完整保留在后
- **每篇笔记自动带 frontmatter**：来源、作者、发布时间、分类、标签、剪藏时间、status，正文前有「来源信息」callout

各平台能拿到什么（诚实版）：

| 平台 | 能拿到什么 | 前提 |
| --- | --- | --- |
| 微信公众号 | 标题/作者/发布时间/全文/图片 | 无需登录 |
| X(Twitter) | 单条推文全文（含长推文）、X 长文 Article、作者/时间/配图 | 无需登录；长文依赖公共代理（syndication+fxtwitter 双通道） |
| 小红书 | 标题/作者/正文/图片 | **必须配置网页版 Cookie** |
| 今日头条 | 头条号图文：标题/作者/发布时间/全文/图片 | 无需登录；桌面链接自动转移动页抓数据 |
| 普通网页/新闻 | 正文/元信息/图片（Readability 提取） | 无 |

## ❌ 不能做什么

- **公众号**：触发「环境异常」风控或文章已删时报错（不会存半页垃圾）；不支持剪公众号主页
- **X**：受限推（年龄/地区）、已删推、纯视频拿不到；推文线程只取单条，会报错或告警
- **小红书**：没 Cookie 基本拿不到正文（平台登录墙）；Cookie 会过期，失效要重新复制；视频笔记只存封面+文字
- **今日头条**：微头条（/w/）、视频页、付费专栏不支持，会明确报错
- **普通网页**：需要 JS 渲染或付费墙的页面拿不到完整正文——会明确告警，建议改用「手动粘贴内容剪藏」
- **不监听剪贴板**：只在你主动点图标/执行命令时读一次剪贴板，不会后台偷看
- **未上架 Obsidian 官方插件市场**，只能手动安装（见下）

## 📋 需要什么

| 项目 | 要求 |
|------|------|
| Obsidian | 1.4.0 及以上 |
| 剪微信公众号 / X / 头条 / 普通网页 | 什么都不用配，装上就能用 |
| 剪小红书 | 电脑浏览器登录 xiaohongshu.com → F12 → Network → 随便点一个 xiaohongshu 请求 → 复制请求头 `Cookie:` 后整串 → 粘贴到插件设置「小红书 Cookie」 |
| 英文翻译 / LLM 分类（可选） | 一个 OpenAI 兼容接口的 API Key；不配则翻译和 LLM 分类完全不生效，其余功能照常 |
| 网络 | 正常访问目标网站；剪 X 长文依赖公共代理可用性 |

> ⚠️ Cookie 和 API Key 只存在你本机 `.obsidian/plugins/shiyue-webclip/data.json`，**请勿分享该文件**。

## 🚀 安装（手动）

1. 到 [Releases](../../releases) 下载最新版 `shiyue-webclip-x.x.x.zip`
2. 解压，把 `main.js`、`manifest.json`、`styles.css` 放进：`<你的仓库>/.obsidian/plugins/shiyue-webclip/`（文件夹不存在就新建，名字必须叫 `shiyue-webclip`）
3. 重启 Obsidian → 设置 → 第三方插件 → 刷新 → 启用「识玥网页剪藏」
4. 首次使用建议先到插件设置里看一遍「诚实声明」

## 📖 怎么用

| 入口 | 位置 | 用途 |
| --- | --- | --- |
| 剪藏剪贴板里的链接 | 左侧栏下载图标 / 命令面板 | 复制任意链接后一键剪藏（最常用） |
| 输入链接剪藏 | 命令面板 | 手动粘贴单个链接 |
| 批量剪藏多个链接 | 命令面板 | 每行一个链接，自动限速抓取 |
| 手动粘贴内容剪藏 | 命令面板 | 动态渲染页/付费墙的兜底：复制正文粘贴进来，照样分类归档 |
| 查看上次剪藏结果 | 命令面板 | 每条链接的成功/跳过/失败原因 |

- **剪贴板确认**：点侧栏图标后先弹窗展示识别到的链接，点「剪藏入库」才写入——复制链接只是想分享给朋友时，点取消即可，零写入。追求速度可在设置改回「一键直接剪藏」。
- **重复链接**：默认弹窗问你是否「重新剪藏一份」（生成带序号的新笔记，不影响旧笔记）；可在设置改为「总是重新剪藏」或「总是跳过」。

## ⚙️ 自动分类规则

设置里按行维护（离线、稳定、毫秒级）：

```
分类名 | 目标文件夹 | 标签1,标签2 | 关键词1,关键词2
科技/AI | 剪藏/科技 | tech,ai | AI,人工智能,大模型,LLM,芯片,开源
```

- 关键词命中最多者胜出；同分取靠前的规则；全不命中进「未分类目录」
- 文件夹/标签可省略（默认 `剪藏/分类名` 和 `[分类名]`）

## 🔧 配置速查

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 笔记保存目录 | `剪藏` | 分类规则可指定子目录 |
| 附件目录 | `剪藏/附件` | 下载的图片 |
| 文件名模板 | `{{date}} {{title}}` | 支持 `{{title}} {{date}} {{datetime}} {{source}} {{author}} {{site}}` |
| 下载图片 | 开 | 失败自动保留原始链接并在笔记里告警 |
| 链接去重 | 开 | 索引存在插件 data.json（上限 3000 条） |
| 重复链接处理 | 询问 | 询问 / 总是重新剪藏 / 总是跳过；重新剪藏不删旧笔记 |
| 剪贴板剪藏方式 | 先确认 | 先弹窗展示链接再入库；可改为一键直接剪藏 |
| 保存前预览 | 关 | 弹窗确认标题/分类/摘要后再入库 |
| 请求超时 / 重试 | 20000ms / 2 次 | 网络错误、5xx、429 自动重试 |
| 英文内容自动翻译 | 开 | 仅 LLM 启用且填 Key 时生效；中文内容不会触发翻译 |
| 批量并发 / 间隔 | 1 / 800ms | 公众号链接自动追加 800ms 限速 |
